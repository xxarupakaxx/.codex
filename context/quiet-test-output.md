# テスト出力の節約

`quiet-run.py`は、テストのログ全文をファイルに保存し、画面には短い結果を表示する。テストの実行範囲、並列数、カバレッジ設定、環境変数、作業ディレクトリは維持する。macOS/LinuxとPython 3で利用できる。

## 使い方

```bash
python3 ~/.codex/scripts/quiet-run.py -- uv run pytest
python3 ~/.codex/scripts/quiet-run.py -- python3 -m unittest discover
```

テストを実行するディレクトリで、`--`の後に普段のテストコマンドと引数を渡す。スクリプトの配置先が異なる場合はパスを読み替える。

## 出力と終了状態

- 開始時にログの保存先、終了時に状態・終了コード・所要時間を表示する。
- 成功時は末尾7行までを含む最大10行。ログの抜粋は4KiB以内。
- 失敗時は末尾80行・16KiB以内を抜粋する。診断に足りない場合は、保存ログを検索して該当箇所を読む。
- 元の終了コードを返す。シグナルによる終了は128＋シグナル番号。自動再実行は行わない。

`PASS`は終了コード0を表す。テスト件数、スキップ、警告、カバレッジは、必要に応じて保存ログの集計を確認する。

## ログの保存

標準出力と標準エラーの全文を、既定で `~/.codex/.local/test-logs/` に保存する。実行ごとに別ファイルを作り、所有者だけが読み書きできる権限を設定する。保存先はコマンドの前に `--log-dir <directory>` を指定して変更できる。

保存先には、同期・Git管理の対象外で、本人だけが管理できるディレクトリを使う。既存ディレクトリの権限は変更しない。ログの自動削除は行わないため、不要になったログは整理する。

機密情報の検出・除去は行わない。機密情報や実データを出力するテストは、保存前にテスト側の出力を修正する。ログ全文はチャットへ貼り付けず、コミットや共有の対象にしない。

## 適用範囲

終了する非対話型のテスト向け。watchモード、対話入力、常駐サーバー、TTYが必要な処理には使わない。実行には元のコマンドと同じ承認・権限が必要で、ラッパーを付けたコマンドにだけ適用される。

中断時は同じプロセスグループへシグナルを転送し、1秒後に残ったプロセスを強制終了する。自分で別グループへ移った子プロセスは管理対象外。

シェルのパイプを使う場合は `bash -o pipefail -c '...'`を明示的に渡し、パイプ途中の失敗が終了コードへ反映されるようにする。

# PRの状態図

登録済みの毎時タスクで、対象PRの変更を状態図として説明する。GitHub投稿・編集の既存承認と対象repositoryを実行前に確認する。

`~/.claude/config/user.json` の `github.watch_repos` を使う。未設定時の従来既定値 `ydb-superapp-server` は、承認済み監視対象と一致する場合だけ使用する。

- 直近24時間以内に作成・更新されたopen PRを、1回最大10件まで処理する。
- `generate-state-diagram` で主要な状態遷移を図示する。新しい図の正本はSVGとし、投稿先の表示方法に合わせて参照する。巨大PRは主要な遷移に絞る。
- 既存コメントの `<!-- claude-generate-diagram -->` を検索し、対象コメントのIDと編集可能な投稿者を確認する。既存ならそのIDを編集し、無ければ承認範囲内で新規投稿する。`--edit-last` だけで対象を選ばない。
- 本文の1行目にマーカーを置く。図が同じなら更新せず、送信結果が不明な場合も既存コメントを確認してから再試行する。

結果は処理・更新・skip件数と失敗を示す。Skillの存在だけで定期実行や投稿権限が付与されたとは扱わない。

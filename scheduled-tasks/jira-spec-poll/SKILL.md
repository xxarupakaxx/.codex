# 担当チケットの仕様書ドラフト

登録済みの毎時タスクで使う。Jira検索は `assignee = currentUser() AND statusCategory != Done AND updated >= -1h ORDER BY updated DESC`。1回最大3チケットを処理する。

チケットコメントに「仕様書ドラフト」がある、または `~/.claude/.local/specs/{チケットキー}.md` が存在する場合はskipし、既存仕様を上書きしない。

説明・受入基準・コメント・関連チケットと該当コードを確認し、概要、背景、機能・非機能要件、技術設計、テスト計画、リスク、サブタスク候補を必要な範囲で記載する。未確認事項を事実として補わず、セキュリティ変更はリスクを明示する。

レビュー前のドラフトとして上記local pathへ保存する。JiraコメントとSlack通知は、定期タスクの既存承認が対象と操作を含む場合に行う。送信前に重複を再確認し、local保存と外部投稿の成否を別々に報告する。
